You can generate Android app icons using:
1. Android Studio: Right-click res folder → New → Image Asset
2. Online tools: https://romannurik.github.io/AndroidAssetStudio/
3. Flutter package: flutter_launcher_icons

Icon sizes:
- mipmap-mdpi: 48x48
- mipmap-hdpi: 72x72
- mipmap-xhdpi: 96x96
- mipmap-xxhdpi: 144x144
- mipmap-xxxhdpi: 192x192
